Firestore Security Rules Action Required

Your Firebase Firestore database blocked reading from search_analytics or activity_logs because security rules haven't permitted these new collections yet.

// Paste this into your Firebase Console > Firestore Database > Rules tab:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Existing rules...

    match /search_analytics/{doc} {
      allow read, write: if true;
    }
    match /activity_logs/{doc} {
      allow read, write: if true;
    }
  }
}
